# 📚 문해력 트레이닝

8살 아이를 위한 문해력 훈련 프로그램입니다. 설치할 것 없이 **`index.html`을 더블클릭**하면 크롬/엣지에서 열립니다.

## 훈련 영역 4가지
| 영역 | 키우는 힘 |
|---|---|
| 📖 낱말 뜻 | 어휘력 (뜻 고르기 · 낱말 고르기 · 빈칸 채우기) |
| 📚 글 읽기 | 독해력 (사실 확인 · 추론 · 어휘 · 중심 생각) |
| 🔢 순서 맞추기 | 글의 흐름·시간 순서 파악 |
| 🔗 이어주는 말 | 문장 사이 관계 이해 (그래서/하지만/왜냐하면 …) |

- **오늘의 훈련**: 하루 약 10분 분량을 영역별로 섞어서 냅니다.
- **자동 단계 조절**: 영역마다 최근 10문제 중 8개를 맞히면 다음 단계로 올라갑니다 (1~3단계).
- **틀린 문제 반복**: 틀린 문제는 다음 훈련에 먼저 다시 나옵니다.
- **🔁 약점 훈련 (변형 문제)**: 틀린 문제를 그대로 다시 내지 않고, 같은 힘을 묻는 다른 모양으로 바꿔서 냅니다. 많이 틀린 문제부터 한 번에 최대 8개를 내고, **연속 2번 맞히면 '극복'** 처리되어 목록에서 빠집니다. 영역을 한 바퀴 다 풀거나(🏁 완주) 훈련 중에 틀린 문제가 있으면 결과 화면에서 권해 줍니다.
  | 영역 | 이렇게 바꿔서 냅니다 |
  |---|---|
  | 낱말 | 뜻 고르기 ↔ 낱말 고르기 ↔ 빈칸 채우기 ↔ 알맞게 쓴 문장 고르기 |
  | 글 읽기 | 틀린 문제와 **같은 유형**(사실·추론·어휘·중심)의 문제를 **다른 글**에서 |
  | 순서 | 그다음에 일어날 일 고르기 / 둘 중 먼저 일어난 일 고르기 / 다시 배열하기 |
  | 이어주는 말 | 같은 이어주는 말이 들어가는 다른 문장 / 그 말이 알맞게 쓰인 문장 고르기 |
- **부모님 화면**: 곱셈 문제로 잠금. 학습 달력, 영역별 정답률, 글 읽기 유형별 약점과 지도 조언, 단계 직접 조정, 기록 백업.
- 🔊 버튼을 누르면 글을 소리 내어 읽어 줍니다 (Windows 한국어 음성 사용).

## 문제 늘리는 법
`data.js`를 메모장으로 열어 같은 모양으로 한 줄씩 추가하면 됩니다.

```js
{ id: "v009", level: 1, word: "새근새근", meaning: "아기가 곤히 잠자며 숨 쉬는 소리", example: "아기가 [새근새근] 자요." },
```

- `id`는 절대 겹치지 않게 (기록이 id로 저장됨)
- `answer`는 보기 번호이며 **0부터** 셉니다
- 단계마다 문제가 많을수록 반복이 줄어듭니다. 단계당 **낱말 20개, 글 10편** 이상을 목표로 늘려 주세요.
